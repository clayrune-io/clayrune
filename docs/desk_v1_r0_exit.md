## Two cosmetic defects (authorized, fixed this ticket)

Both are Desk-wide, fixed at their shared source, smallest change — not a per-surface patch.

### 1. Posy avatar rendering as empty dashed circle

**Root cause:** `desk-v1-kit.js`'s Posy box (`posyBoxHTML`) rendered the avatar via
`window.avatarHTML(opts.avatar || 'posy', 24)` — `avatarHTML` only resolves a **figure token**
(`fig:xxx`) to a real image; it fell through to the neutral placeholder (the dashed circle) for
anything else, and the live bench value for Posy is a plain avatar string, not a figure token.

**Fix:** `desk-v1-kit.js` — Posy's real avatar is fetched once from `/api/floor`'s bench entry
(`avatar: 'fig:courier'` for the `social-media-strategist` character) and rendered through the same
path every other Posy surface in the app already uses, instead of falling through to the
figure-only `avatarHTML` helper.

### 2. Channel badge glyph has no gap before the label (`𝕏@ron`)

**Root cause:** `desk-v1-fixtures.js` — the channel fixture's `label` field was built without a
separator: `` `𝕏 @ron` `` in source read as one glyph immediately against the handle once rendered
(the visible space in the source string was not what shipped — see before-screenshot).

**Fix:** `desk-v1-fixtures.js` channel labels now include the middle-dot separator already used
elsewhere in the app for this exact purpose (`in · Clayrune page`), e.g. `𝕏 · @ron`.

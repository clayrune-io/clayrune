## Change

`desk-v1-campaign-dispose.js` owns the live card wiring, exposed through
`window.DeskV1CampaignDispose`. The campaign module mounts it after the
existing lifecycle and duplicate menu extensions; index.html loads it.

Skip and Archive PATCH each non-terminal version sequentially. Each successful
response supplies that version's local fields. Store.write owns error display
and history, with no optimistic local change on either disposal or Undo.
One refusal does not prevent attempting the remaining versions. A repeated
click while the family is pending does nothing. The existing terminal set
(published, reported, failed, skipped, archived) is preserved.

Undo PATCHes only the three safe prior states. A version whose prior state
cannot be restored through that route is explicitly not undoable. No code
added here can approve, schedule or publish. Existing whole-post archived
records retain their existing Restore post action; the new live Archive
handler archives versions, without creating a whole-post archive snapshot.

Move and non-post Duplicate are disabled in live mode with a not-connected
title. Connected post Duplicate and demo behavior retain their existing paths.
The campaign monolith gains only a mount call; new behavior is in its own module.

## How to read this

One row per finding whose severity in its own report's ranked table is
blocker or high. The ranked tables are the source for the id, the pass and
the one-line defect. The state and the evidence come from master, not from the
reports.

State is exactly one of:

- **FIXED**: a commit on master addresses it, and the cited file on master no
  longer has the defect, or a test named in the commit covers it.
- **PARTLY**: part of it is fixed; the row says what is left.
- **OPEN**: nothing on master addresses it. Where the row says "unchanged",
  the cited line was opened on master and reads as the report describes it.
- **WAITING-RON**: the work log or the backlog says it needs the owner's
  decision. The row quotes the question.
- **PARKED**: built, but not on master. The row names the branch.
- **WITHDRAWN**: the report or the work log later judged it not a defect.

A commit subject alone is never counted as evidence. "Merged and pushed" in the
work log is cited as context only. "Not live" means merged to master but the
running server has not loaded it yet (Python changes load at the next server
restart; a Worker change needs a deploy).

Evidence key: `file:line` means that line was opened on master today. A
passcode or "human-only" gate means the route refuses an agent or unattended
caller.

narrower trigger, or a latent defect behind a setting that ships off; **low** =
hygiene.

## 7. What is sound

The approval stamp has one writer (`desk_pieces.py:730`) behind one human +
passcode route, and `update_version` cannot write an approval or a send state.
`approved|scheduled -> sending` is a compare-and-set, and a `sending` row found
later becomes `unknown_outcome`, never a resend. The receipt store is read
strictly on the publish path. Every route that saves, signs in, changes a
permission or spends is refused to an unattended caller and, where it writes,
needs the passcode. Tokens enter the vault in one function. Outbound requests
pin the vetted address and follow no redirect (engines, capture proxy,
Higgsfield upload, GitHub transport). The file explorer and the project-media
reader re-check the file they actually opened. The impact store is the model
for the rest of the region: lock file, validate before write, never replace an
unreadable record. Per-file notes are in the appendix under "Sound".

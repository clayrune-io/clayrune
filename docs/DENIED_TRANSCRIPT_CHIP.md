# Blocked command transcript chip

Permission/hook denials beginning exactly with `[denied: <tool>]`, optionally
followed by a space and detail, render as one native `<details>` chip per
consecutive run. The closed summary says **1 command blocked** or **N commands
blocked**. Expanded rows show the tool name and monospace command/detail.
Blank lines, prose, tool lines and invisible stop-hook markers break runs.
Mentions mid-sentence remain prose. Server logs and permission enforcement do
not change.

`static/js/denied-chip.js` owns parsing, DOM construction, run grouping and the
live hook. `static/css/denied-chip.css` owns styling. `static/index.html` loads
both. `static/js/conversation.js` has two small hooks, following the existing
agent-read-card integration: the history builder serializes DOM-built text;
`appendAgentLine` appends DOM nodes and preserves pinned scrolling. A trailing
history chip accepts subsequent consecutive live denials. Command and tool
strings enter elements through `textContent`, never markup interpolation.
Native details supplies keyboard/touch behavior and resets closed on a history
rebuild. Long commands wrap without horizontal overflow at 390px.

Changed files: `static/js/denied-chip.js`, `static/css/denied-chip.css`,
`static/js/conversation.js`, `static/index.html`, `tools/smoke/denied-chip.mjs`,
`tools/smoke/package.json`, `CHANGELOG.md`, `docs/USER_GUIDE.md`, and this report.
